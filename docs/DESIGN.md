# Namotai — Design Document

**Версия:** 0.3 (MVP)
**Дата:** 2026-10-14
**Статус:** утверждён к реализации

---

## Обзор

**Namotai** — сервис, который превращает пассивный учебный материал (видео или текст) в активные задания для закрепления.

Пользователь загружает видеофайл или текстовый документ (например, главу учебника). Система транскрибирует видео через Whisper, нормализует текст, затем LLM генерирует конспект и набор вопросов разной сложности. Результат можно экспортировать.

**Ключевая идея:** не заставлять пользователя смотреть/читать пассивно, а сразу давать инструмент проверки понимания.

**Ключевое требование к качеству:** задания должны быть осмысленными и интересными. LLM без настройки часто выдаёт сырые, поверхностные вопросы — промпт-инжиниринг и контроль качества генерации являются приоритетом, а не второстепенной задачей.

## Цели и не-цели

### Цели MVP
- Принять видеофайл или текстовый документ от пользователя
- Транскрибировать видео с таймкодами
- Извлечь и нормализовать текст из документов
- Сгенерировать 5–10 качественных вопросов разной сложности через LLM
- Дать пользователю выбрать сложность и количество
- Показать результат и дать экспорт

### Не-цели MVP
- Приём ссылок (YouTube / VK / Rutube)
- Аккаунты, авторизация, история
- OCR сканов и изображений
- Интерактивное прохождение с проверкой ответов
- API для LMS
- Мультиязычность интерфейса (русский в MVP, английский — потом)
- Хранение исходных файлов после обработки
- Асинхронная обработка (Celery / Redis / очередь)
- Предпросмотр транскрипта до генерации

## Пользовательские сценарии

### Сценарий A: Видео
1. Пользователь открывает Namotai
2. Переходит на вкладку «Видео»
3. Загружает файл `lecture.mp4` (любой видеоформат)
4. Выбирает сложность «средняя», количество вопросов «7»
5. Нажимает «Обработать»
6. Видит индикатор обработки
7. Получает конспект + список вопросов с ответами
8. Экспортирует в Markdown или PDF

### Сценарий B: Текст
1. Пользователь открывает Namotai
2. Переходит на вкладку «Текст»
3. Загружает `chapter_3.docx` / `.pdf` / `.txt` или вставляет текст в поле
4. Выбирает сложность и количество
5. Нажимает «Обработать»
6. Получает результат аналогично сценарию A

## Архитектура

### Компоненты

```
┌─────────────┐      ┌──────────────┐      ┌─────────────┐
│  Next.js    │─────▶│   FastAPI    │─────▶│  PostgreSQL │
│  Frontend   │      │   Backend    │      │             │
└─────────────┘      └──────┬───────┘      └─────────────┘
                            │
              ┌─────────────┼─────────────┐
              ▼             ▼             ▼
        ┌──────────┐  ┌──────────┐  ┌──────────┐
        │ ffmpeg   │  │ Whisper  │  │   LLM    │
        │ (local)  │  │(Cloud.ru)│  │(Cloud.ru)│
        └──────────┘  └──────────┘  └──────────┘
```

**Обработка синхронная.** HTTP-запрос открыт до получения результата. Никаких очередей, воркеров и брокеров.

### Роли компонентов

| Компонент | Роль |
|---|---|
| **Next.js** | UI: загрузка, выбор параметров, индикатор обработки, результат, экспорт |
| **FastAPI** | REST API, приём файлов, синхронная обработка, выдача результатов |
| **PostgreSQL** | Хранение результатов генерации |
| **ffmpeg** | Извлечение аудио из видеофайла (локально в контейнере api) |
| **Whisper (Cloud.ru)** | Транскрипция аудио с таймкодами — **0.005 ₽/сек** |
| **LLM (Cloud.ru)** | DeepSeek V4 Flash — **46 ₽ / 89 ₽ за 1M токенов** |
| **Файловое хранилище** | Временное хранение загруженных файлов до обработки |

## Экономика

### Тарифы

| Компонент | Тариф |
|---|---|
| Whisper (Cloud.ru) | 0.005 ₽ / секунда аудио |
| LLM — вход | 46 ₽ / 1M токенов |
| LLM — выход | 89 ₽ / 1M токенов |

### Себестоимость одной задачи

| Длина видео | Whisper | LLM | **Итого** |
|---|---|---|---|
| 5 мин | 1.50 ₽ | 0.50 ₽ | **2.00 ₽** |
| 15 мин | 4.50 ₽ | 1.31 ₽ | **5.81 ₽** |
| 30 мин | 9.00 ₽ | 2.27 ₽ | **11.27 ₽** |
| 60 мин | 18.00 ₽ | 4.10 ₽ | **22.10 ₽** |
| 2 часа | 36.00 ₽ | 7.75 ₽ | **43.75 ₽** |

**Whisper — ~80% себестоимости. LLM — ~20%.**

### Оценка на 1000 задач (30 мин видео)

- Whisper: 9 000 ₽
- LLM: 2 270 ₽
- **Итого: ~11 270 ₽**

### Защита от злоупотреблений

| Механизм | Значение |
|---|---|
| Лимит размера файла | 100 МБ |
| Максимальная длина видео | 2 часа |
| Rate limit по IP | 5 задач / сутки |
| Таймаут HTTP | 600 секунд |
| Логирование стоимости | На каждую задачу |

## API

### Генерация

**`POST /api/generate`**

Content-Type: `multipart/form-data`

| Поле | Тип | Обяз. | Описание |
|---|---|---|---|
| `file` | file | да* | Видео или документ |
| `text` | string | да* | Текст (альтернатива файлу) |
| `source_type` | string | да | `video` / `text` |
| `difficulty` | string | да | `easy` / `medium` / `hard` |
| `question_count` | int | да | 5–10 |

\* Либо `file`, либо `text`.

**Ответ 200:**
```json
{
  "id": "uuid",
  "summary": "...",
  "questions": [
    {
      "question": "...",
      "type": "single_choice",
      "options": ["...", "...", "...", "..."],
      "answer": "...",
      "source_ref": {"start": 12.5, "end": 30.0}
    }
  ],
  "cost": {
    "whisper": 9.00,
    "llm_input": 1.38,
    "llm_output": 0.89,
    "total": 11.27
  }
}
```

**Ответ 413** — превышен лимит размера файла.
**Ответ 422** — невалидный формат или параметры.
**Ответ 500** — ошибка обработки с понятным `error_message`.

### Получение результата

**`GET /api/results/{id}`**

Возвращает сохранённый результат по UUID.

### Экспорт

**`GET /api/results/{id}/export?format=md|pdf|json`**

Возвращает файл.

### Health

**`GET /health`**

```json
{"api": "ok", "db": "ok"}
```

## Пайплайн обработки

### Видео (синхронно внутри POST /api/generate)

```
1. Приём файла → сохранение в MEDIA_DIR/{uuid}/source.ext
2. Проверка размера (≤ 100 МБ) и длительности через ffprobe (≤ 2 часа)
3. ffmpeg -i source.ext -vn -ac 1 -ar 16000 audio.wav
4. Отправка audio.wav в Whisper (Cloud.ru)
5. Получение сегментов {start, end, text}
6. Удаление source.ext и audio.wav
7. Отправка транскрипта в LLM с промптом
8. Парсинг JSON-ответа
9. Сохранение в results + расчёт стоимости
10. Возврат результата в HTTP-ответе
```

### Текст

```
1. Приём файла или текста → сохранение в MEDIA_DIR/{uuid}/source.ext
2. Парсинг: txt / docx / pdf
3. Нормализация, разбивка на чанки (если > N символов)
4. Удаление source.ext
5. Отправка текста в LLM
6. Парсинг JSON-ответа
7. Сохранение в results + расчёт стоимости
8. Возврат результата в HTTP-ответе
```

### Обработка ошибок

- Невалидный формат → 422 с понятным сообщением
- Превышен лимит размера → 413
- Видео длиннее 2 часов → 422
- Ошибка Whisper → retry 2 раза (внутри запроса), затем 500
- Ошибка LLM / невалидный JSON → retry 2 раза, затем 500
- Таймаут ffmpeg → 500
- Временные файлы удаляются в `finally` в любом случае

## Промпт для LLM

### Вход

- Текст (транскрипт или документ)
- Сложность
- Количество вопросов
- Тип источника (`video` / `text`)

### Выход (строгий JSON)

```json
{
  "summary": "Конспект в 3-7 предложениях",
  "questions": [
    {
      "question": "Текст вопроса",
      "type": "single_choice | multiple_choice | open",
      "options": ["A", "B", "C", "D"],
      "answer": "Правильный ответ или массив",
      "source_ref": {"start": 12.5, "end": 30.0}
    }
  ]
}
```

Для текста `source_ref` — `{"chunk": 3}` или `{"section": "..."}`.

### Требования к промпту

- Язык вопросов = язык исходного материала
- Сложность влияет на:
  - `easy` — факты, определения, простое воспроизведение
  - `medium` — понимание, связи, применение
  - `hard` — анализ, синтез, оценка, нестандартные формулировки
- Вопросы не должны дублироваться
- Для `single_choice` — ровно 4 варианта
- Ответ — строго валидный JSON без обёрток
- **Качество важнее количества:** лучше 5 осмысленных вопросов, чем 10 поверхностных
- **Запрет на шаблонность:** избегать формулировок «Что такое X?», «Перечислите...» без контекста
- **Привязка к материалу:** каждый вопрос должен опираться на конкретный фрагмент источника

### Контроль качества (пост-обработка)

После получения ответа от LLM:
1. Валидация JSON-схемы
2. Проверка: ровно N вопросов, у `single_choice` — 4 опции
3. Проверка на дубликаты (по нормализованному тексту вопроса)
4. Проверка `source_ref` на попадание в диапазон транскрипта
5. При провале — повторный запрос с уточнением

## Frontend

### Страницы

| Путь | Назначение |
|---|---|
| `/` | Главная: две вкладки (Видео / Текст) + форма |
| `/results/{id}` | Результат по UUID |

### Главная

**Вкладка «Видео»:**
- Drag&drop или кнопка выбора файла
- Отображение имени и размера
- Выбор сложности (радио)
- Выбор количества вопросов (слайдер 5–10)
- Кнопка «Обработать»

**Вкладка «Текст»:**
- Загрузка файла (txt / docx / pdf) ИЛИ textarea для вставки
- Те же настройки
- Кнопка «Обработать»

### Индикатор обработки

Так как обработка синхронная, прогресс по этапам недоступен. Вместо этого:
- Спиннер с текстом «Обрабатываем...»
- Примерное время: «Обычно занимает 1–3 минуты»
- Предупреждение: «Не закрывайте вкладку»

### Страница результата

- Блок «Конспект»
- Список вопросов (сворачиваемые ответы)
- Для видео — ссылка на таймкод (если возможно)
- Кнопки экспорта: MD / PDF / JSON
- Отображение стоимости обработки (для внутреннего мониторинга)

## Ограничения и допущения

### Ограничения MVP

- Нет авторизации — все результаты анонимные, доступ по UUID
- Нет истории — результат живёт, пока есть запись в БД
- Нет интерактива — ответы показываются сразу
- Нет OCR — сканы PDF не поддерживаются
- Один язык интерфейса — русский
- Лимит файла — 100 МБ
- Лимит длины видео — 2 часа
- Rate limit — 5 задач / сутки / IP
- Нет прогресса по этапам (синхронная обработка)
- Нет восстановления после падения сервера

### Допущения

- Пользователь загружает свои файлы или материалы, на которые имеет право
- Файлы не хранятся после обработки
- Whisper и LLM доступны через Cloud.ru с оплатой по факту
- Стоимость каждой задачи логируется
- HTTP-таймаут 600 секунд достаточен для 2-часового видео
- Все видеоформаты, которые понимает ffmpeg, поддерживаются

## Безопасность и приватность

- Файлы хранятся временно и удаляются после обработки (в `finally`)
- UUID результата — единственный ключ доступа, без перебора
- Rate-limit на генерацию (по IP)
- Валидация MIME и расширения
- Ограничение размера файла
- Секреты Cloud.ru — только в `.env`, не в репозитории
- Логи не содержат ключей и персональных данных

## Метрики MVP

- Время от загрузки до результата (цель: < 3 мин для 10-мин видео)
- Доля успешных задач (цель: > 90%)
- Средняя себестоимость одной задачи
- Общая сумма расходов на Whisper + LLM
- Количество экспортов на задачу (косвенный признак полезности)
- **Субъективная оценка качества вопросов** (собирать фидбэк)
